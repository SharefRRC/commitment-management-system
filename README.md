# Commitment Management System API

## Overview

The Commitment Management System API is a back-end application that helps users manage future commitments and deadlines.

Unlike a traditional to-do list, each commitment includes both:

* A due date
* A must-start-by date

This helps users understand not only when something is due, but also when they should begin working on it to avoid falling behind.

## Technologies

* TypeScript
* Express
* Firebase Firestore
* Firebase Authentication
